# Architecture and slide graphic provenance

All Deal Passport SVG diagrams and slide illustrations in this directory were authored for this project on 26 October 2026 from the implemented source and current verification evidence. The system diagram uses named trust boundaries and routed connectors inspired by Oleksiy’s supplied [ProofTrace reference](https://github.com/aonishchenko/prooftrace/blob/main/docs/architecture-assets/prooftrace-system.svg); its nodes, copy and data flow describe Deal Passport. Original vector shapes were authored in code; PNG files are deterministic renders of their matching SVGs. No stock photography, real identity document, customer property or AI-generated photo is represented.

The black/yellow slide graphics follow the supplied HackMeridian deck identity. The organizer’s Meridian mark remains part of that supplied template and is not included in these original illustrations.
